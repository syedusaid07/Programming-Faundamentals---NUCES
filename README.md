## 🧠 Core Theoretical Topics Covered

Here is a quick overview of the fundamental concepts explored through these assignments:

* **Basic Syntax & Data Types:** Variables, constants, type casting, and basic I/O operations.
* **Control Structures:** Conditional statements (`if`, `else`, `switch`) and looping constructs (`for`, `while`, `do-while`).
* **Modular Programming:** Functions, scope of variables, parameter passing (by value vs. by reference), and recursion.
* **Data Structures:** 1D & 2D Arrays, strings, pointers, and structures.
