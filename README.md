## 📂 Repository Branch Structure

This repository is organized into specific branches to keep different types of academic work neatly separated:

| Branch Name | Description | What You'll Find Here |
| :--- | :--- | :--- |
| `🌿 lab` | **Hands-on Lab Sessions** | In-class coding tasks, practical implementations, and guided problem-solving. |
| `🌿 post-lab` | **Post-Lab Assignments** | Extended homework exercises, advanced challenges, and lab reports. |
| `🌿 pf-theory` | **Theory & Assignments** | Written assignments, conceptual problem sets, quizzes, and university submissions. |


## 🚀 Quick Navigation

To switch between different sections of my coursework, use the branch selector on GitHub or run the following command in your terminal:

```bash
# Switch to Lab tasks
git checkout lab

# Switch to Post-Lab tasks
git checkout post-lab

# Switch to Theory assignments
git checkout pf-theory 

```
